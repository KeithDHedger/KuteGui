# KuteGui
KUTEGui is a Qt-based graphical user interface frontend for the K.U.T.E. (Keith's Universal Tag Editor) command-line audio tagging utility  

Usual build:
```
./autogen.sh --prefix=/usr
make
[sudo] make install
```

You will need to install the Qt6 development files, and K.U.T.E. available here:  
https://github.com/KeithDHedger/Kute
