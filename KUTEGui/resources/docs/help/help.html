KUTEGui Help

KUTEGui is a Qt-based graphical user interface frontend for the K.U.T.E. (Keith's Universal Tag Editor) command-line audio tagging utility.

Requirements & Supported Formats

  • Backend Dependency: The kute command-line executable must be installed and available in your system $PATH. If missing, KUTEGui will exit with a message directing you to the K.U.T.E. repository.
  • Supported Audio Formats: .mp3, .m4a, .flac, and .mp4 ( video files ).

Interface Overview

The main window consists of a menu bar, a quick-access toolbar, a tag editor section, a file list, and a status bar.


Tag Fields

Each metadata tag row has three controls:

  1. Static Checkbox: When checked, the text in this field is locked. Selecting a different file in the list will not overwrite or clear the field's value, making it easy to apply shared metadata (such as Artist, Album, or Year) across multiple tracks.
  2. Tag Name Checkbox: Determines whether this specific tag will be included when writing tags to a file. All tag checkboxes are selected by default when KUTEGui starts.
  3. Text Input: Displays the current tag value read from the selected file and allows you to edit it.

File List

  • Displays loaded audio files sorted alphabetically by name.
  • Clicking or navigating to a file automatically queries its metadata via kute -q and populates all non-static fields.
  • Context Menu (Right-Click): Right-clicking any file in the list lets you Copy Name (filename only) or Copy Path (full directory path and filename) to the clipboard.

Menus & Toolbar Actions

File Menu

  • Open File: Browse for and load a single supported audio file into the list.
  • Open Folder: Select a directory to load all supported audio files inside it. KUTEGui remembers your last opened folder and window geometry between sessions.
  • Copy Tags to Clipboard: Copies all current tag fields and their values to the system clipboard formatted as TagName="Value".
  • Quit: Saves your preferences and closes the application.

Tags Menu

  • Write Tags For File: Prompts for confirmation, then writes all checked tags to the currently selected file.
  • Write Tags For All Files: Prompts for confirmation, then iterates through every file in the list and writes all checked tags to each file.
  • Select All Tags: Checks the inclusion box for every tag field.
  • De-Select All Tags: Unchecks the inclusion box for every tag field.
Tip for Batch Tagging: To apply the same album, artist, or year to an entire folder without overwriting individual track titles or numbers, check Static on the shared tags, ensure only those shared tag checkboxes are checked (or use De-Select All Tags and re-check just the ones you want to update), and click Write Tags For All Files.

Help Menu

  • About: Displays version details, author credits, GPLv3 license text, and Qt framework information.
  • Help: Opens this help documentation window.

Troubleshooting

  • Error Logs: Any standard error output generated by kute when writing tags is appended to /tmp/kutegui-error.log.
